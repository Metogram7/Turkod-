Türkce Programlama

TÜRKOD Nedir?

Türkce anahtar kelimeler ile yazılan, tamamen Türkce arayüzü ve Türkce hata mesajları sunan programlama dilidir.

Türkçe ile Düşün, Türkce ile Kodlayın

TÜRKOD, programlamayı herkes için erişilebilir kılmayı hedefleyen özel bir programlama dilidir. İngilizce bilmeden, Türkce anahtar kelimeler ile kod yazabilir, hata mesajlarını anlayabilirsiniz.

Güncel Teknolojiler (Node.js, Electron, PowerShell) üzerine inşa edilmiştir. Masaüstü uygulamaları, dosya işlemleri, web istekleri, yapay zeka, çizim ve müzik gibi pek çok alanda kullanılabilir.

# İngilizce Anahtar Kelimeler name = input("Your name: ") age = int(input("Your age: ")) if age >= 18: print("You are adult") else: print("You are minor")

// İngilizce Anahtar Kelimeler let name = prompt("Your name: "); let age = parseInt(prompt("Age: ")); if (age >= 18) { console.log("You are adult"); } else { console.log("You are minor"); }

// İngilizce + Karmaşık Söz Dizimi string name = Console.ReadLine(); int age = int.Parse(Console.ReadLine()); if (age >= 18) { Console.WriteLine("Adult"); } else { Console.WriteLine("Minor"); }
