TÜRKOD'U BERABER GELİŞTİRELİM!

TÜRKOD, topluluk katkılarıyla büyüyor. Sen de kendi modülünü oluştur, binlerce geliştiriciye ulaş. Nasıl mı? İşte rehberimiz.

📦

Modül Nedir?

Modül, TÜRKOD'un yeteneklerini genişleten paketlerdir. Bir modül, birden fazla dosya ve komut içerebilir.

  • .turkod uzantılı JSON paketi
  • İçinde kod dosyaları ve meta bilgi
  • Tek dosya halinde paylaşılabilir
  • Stüdyo üzerinden kurulabilir
💡

Bize Faydası

Her yeni modül, TÜRKOD ekosistemini güçlendirir:

  • Daha zengin bir dil havuzu
  • Yeni başlayanlar için hazır çözümler
  • Gerçek dünya uygulamaları
  • Ortak bilgi birikimi
🎁

Sana Faydası

Modül oluşturmak senin için de faydalı:

  • Portföyünü güçlendirir
  • TÜRKOD topluluğunda tanınırsın
  • Kod becerilerini geliştirirsin
  • Başkalarının işine yararsın

🛠️ Nasıl Yapılır?

1

Modül Oluştur

Terminalde komutu çalıştır, modülün ismiyle otomatik oluşsun.

modül_oluştur {isim}
2

Kodlarını Yaz

Oluşan klasördeki dosyalara kodlarını yaz. Referans'tan yardım al.

3

Derle

Terminalde derleme komutunu çalıştır, .turkod paketini oluştur.

modül_derle {isim}
4

Gönder

Aşağıdaki formu doldur, .turkod dosyanı yükle. İncelemeye alınır!

🚀 Hazırsan Başla!

İlk modülünü oluşturmak için Referans sayfasındaki komutları incele.

📚 Referans

📋 Örnek: modül_oluştur ile Neler Oluşur?

Terminalde modül_oluştur MerhabaDunya yazınca şu klasör ve dosyalar oluşur:

index.tr — Modül tanımı (dışa aktarımlar) 
# MerhabaDunya Modülü
# Bu dosya modülün dışa aktarımlarını tanımlar.

dışa_aktar = {
  # Üye fonksiyonları buraya ekleyin
}
📌 Bu dosyada ne yapılır?
• Modülün dışarıya açacağı fonksiyon ve değişkenler burada tanımlanır
• dışa_aktar = { ... } içine eklenen isimler, başka dosyalarda kullanılabilir
• Boş bırakılırsa modülün hiçbir üyesi dışarı açılmaz
modul.tr — Çalışan örnek kod 
# MerhabaDunya Modülü — Çalışan Örnek

# Modülü içe aktar
# içe_aktar MerhabaDunya

# Örnek kullanım
yazdır("MerhabaDunya modülü başarıyla yüklendi!")
📌 Bu dosyada ne yapılır?
• Modülün test kodları burada yazılır
• içe_aktar ile kendi modülünüzü içe aktarıp test edebilirsiniz
• Bu dosya .turkod paketine dahil edilmez, yalnızca geliştirme içindir
modul.json — Modül künyesi (derleme için) 
{
  "isim": "MerhabaDunya",
  "version": "1.0.0",
  "aciklama": "",
  "yazar": ""
}
📌 Bu dosyada ne yapılır?
• aciklama ve yazar alanlarını doldurmayı unutma!
• modül_derle bu dosyadan bilgileri okur
• Her derlemede version otomatik artar (1.0.0 → 1.0.1)
• Bu dosyayı silme! Derleme bundan beslenir
Oluşan klasör yapısı 
MerhabaDunya/
├── index.tr      # Modül tanımı
├── modul.tr      # Çalışan örnek
└── modul.json    # Künye (aciklama, yazar, versiyon)
📌 Tam akış:
1. modül_oluştur MerhabaDunya → klasör ve dosyalar oluşur
2. index.tr'de dışa aktarımları, modul.tr'de test kodlarını yaz
3. modul.json'daki aciklama ve yazar'ı doldur
4. modül_derle MerhabaDunya → MerhabaDunya.turkod paketi oluşur
5. Aşağıdaki formu doldur, .turkod'u yükle — tamam! 🚀
MerhabaDunya.turkod — modül_derle çıktısı 
{
  "turkodModul": true,
  "ad": "MerhabaDunya",
  "version": "1.0.0",
  "aciklama": "Merhaba Dünya programı.",
  "yazar": "Geliştirici",
  "dosyalar": {
    "index.tr": "dışa_aktar = {\n  # ...\n}",
    "modul.tr": "yazdır(\"MerhabaDunya modülü yüklendi!\")"
  }
}
📌 Bu dosya otomatik oluşur, elle düzenleme yapma!
• modül_derle komutu modul.json'u okur, .tr dosyalarını paketler
• turkodModul: true imzası otomatik eklenir
• Bu dosyayı bu sayfadan yükle, incelemeden geçsin! 📦

Modülünü Gönder

Stüdyo'da modül_derle ile derlediğin .turkod paketini yükle, incelemeden geçsin ve mağazada yayınlansın. 🚀

ℹ️ Nasıl modül derlerim?
1. Stüdyo terminalinde modül_oluştur ModülAdın ile projeni aç
2. Kodunu yaz, modul.json künyesindeki açıklama ve yazar alanlarını doldur
3. modül_derle ModülAdın ile .turkod paketini oluştur
4. Paketi bu sayfadan gönder — gerisini bize bırak! 😊
